Support

We answer within two business days.

Email support@mekhaneapps.com. Usually we reply the same day; we commit to two business days (Monday to Friday, Argentina time, UTC−3).

What to include

  • Which app and which Atlassian product (for example, “Rich Text Notes, Jira Cloud”).
  • What you expected and what happened instead, with a screenshot if you can.
  • Your site URL (yourcompany.atlassian.net) so we can check the installation. Never send passwords or API tokens.

Security issues

If you believe you found a security vulnerability in one of our apps, email support@mekhaneapps.com with “Security” in the subject. We acknowledge security reports within one business day and follow Atlassian’s Security Bug Fix Policy for Marketplace apps.

Feature requests

Send them to the same address. We build what customers ask for twice, in the order they ask.

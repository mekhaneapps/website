Rich Text Notes for Jira

A dashboard gadget for formatted notes: headings, lists, checklists you can tick from the dashboard, links, quotes and code. Matches Jira’s light and dark themes.

Get it on the Marketplace   Support

Install

  1. A Jira site administrator installs the app from the Atlassian Marketplace (Apps → Explore more apps → search “Rich Text Notes”).
  2. Open any dashboard you can edit and choose Add gadget.
  3. Search for Rich Text Notes and add it. The gadget appears empty with a hint to edit it.

Write a note

  1. Open the gadget menu (···) and choose Edit.
  2. Write using the toolbar or Markdown-style shortcuts: # heading, - bullet list, 1. numbered list, [ ] checklist, > quote, ``` code block.
  3. Press Save. The note is stored and shown to everyone who can see the dashboard.

Checklists on the dashboard

Checklist items can be ticked directly in the dashboard view, without opening the editor. Each change is saved immediately and visible to everyone viewing the dashboard. Ticked items are shown struck through.

Permissions and who can edit

Anyone who can edit the dashboard can edit the note; anyone who can view the dashboard can read it and tick checklist items. The gadget follows Jira’s dashboard permissions and adds none of its own.

Limits

  • One note per gadget. Add more gadgets for more notes.
  • A note can hold up to 100 KiB of formatted text, roughly 15,000 words. The editor tells you if you reach the limit.
  • Notes are text only. Images and attachments are not supported in this version.
  • Copying a dashboard creates new gadgets with empty notes; notes are not duplicated.

Where your data lives

Notes are stored in Atlassian’s Forge hosted storage, inside your Atlassian site’s data boundary. The app has no servers of its own and sends nothing outside Atlassian. See the privacy policy for details.

Uninstalling the app removes the gadgets from dashboards. Stored notes are deleted according to Atlassian’s Forge storage retention after uninstall.
